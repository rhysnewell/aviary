# Aviary PDF manual

The Aviary manual combines the website's canonical documentation into a single
searchable document for offline reading, archiving and sharing alongside an
analysis.

[Download the current Aviary manual](https://snh-star.github.io/aviary/pdf/aviary-manual.pdf){ .md-button .md-button--primary }

The PDF is generated during the documentation build from the same Markdown
pages used by this website. Command behaviour and defaults should still be
checked against `aviary <command> --help` for the installed software version.

!!! tip

    Link to the website when possible so readers benefit from search, cross-links
    and future corrections. Archive the PDF when a fixed documentation snapshot
    is required for a reproducible analysis.
