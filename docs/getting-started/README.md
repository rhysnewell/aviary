# Getting started

Set up Aviary, verify its reference data, and run a first analysis.

1. [Install Aviary and configure databases](../installation.md).
2. Use the [quickstart](quickstart.md) for the shortest useful run.
3. Follow the [first complete analysis](first-analysis.md) to learn
   how inputs, stages, outputs and logs fit together.

For production work, also read [reproducibility](../advanced/reproducibility.md)
before starting the analysis.
